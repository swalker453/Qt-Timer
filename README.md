# 隅田川散歩人企画 謹製タイマー

WindowsとAndroidで動くQt/C++製タイマー

1時間ごとに椅子から立ち上がって屈伸運動をした方が、結局は長期的に良いらしいです

## 制作

- 効果音提供：[ザ・マッチメイカァズ](https://osabisi.sakura.ne.jp/m2/)様
- 制作：[隅田川散歩人企画](https://swalker.sakura.ne.jp)
