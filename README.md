# 隅田川散歩人企画 謹製タイマー

## WindowsとAndroidで動くQt/C++製タイマー

1時間ごとに椅子から立ち上がって屈伸運動をした方が結局は長期的に見ると良いらしいのですが、なぜならぶっ続けで数時間×数セットPC作業した次の日とか基本的に目と腰が死んでるからなのですが、しかし気を抜くとしばしばそういうことが発生してしまうのですが、しかし既製の色々出来るタイマーとかでそれを防ぐべくタイマーをかけようとしても1時間を設定するのがめんどくさかったりして結局やらないので、じゃあボタン１回押したら1時間タイマーが即設定出来るだけのアプリを自分で作ればいいやんと思ったので、

作りました！！！！（一応1時間以外も好きな時間を～99:59:00までの範囲で設定できます）

## 解説

- なぜか無駄にWindows/Androidのクロスプラットフォームです。
- Windows版は zip を展開して `Timer.exe` を実行してください。
- Android版は APK をインストールしてください。
- Android版のインストールには「不明なアプリのインストールを許可」が必要な場合があります。

## 既知のバグ（めんどいので直しません）

- タイマーアップしたあと、「スタート」でリスタートすると、文字色が赤いままです。
- そもそも「スタート」「リスタート」ボタンを分ける必要がなかった気がします。
- 複数起動出来てしまうのでなんかタスクトレイに複数常駐出来てしまってなんか微妙です。
- 分・秒の入力欄の上限を60にしたのですが、よく考えると59にすべきでした。
